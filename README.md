🧗‍♂️ Gym Selector

**Gym Selector** is a simple BeeWare app that randomly selects a rock climbing gym from a predefined list.  
It was created as one of my first experiments with the BeeWare framework.

---

## 🚀 Features

- Click a button to randomly choose a climbing gym.
- Outputs the selected gym in a text field.
- Easy-to-use and minimal UI built with Toga (BeeWare).

---

## 🖼️ Example Gyms in the List

- Vertical Hold: San Marcos
- Vertical Hold: Old Town
- Mesa Rim: Mira Mesa
- The Wall
- Vital: Oceanside  
_(and others...)_

## ▶️ How to Run

1. Make sure you have [Briefcase and BeeWare installed](https://beeware.org/getting-started/).
2. Clone or copy this script into a BeeWare project (`briefcase new` if starting from scratch).
3. Replace the `app.py` or main app file with this one.
4. Run the app:

```bash
briefcase dev
